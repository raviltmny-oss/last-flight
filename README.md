# Последний рейс

Выживание на острове: почините самолёт RA-1904 и улетайте, пока пираты не растащили его по частям. Одному или вдвоём.

Этот репозиторий — сайт игры для Railway:

- `/` — игра в браузере. На iPhone её можно поставить на экран «Домой» (Safari → «Поделиться» → «На экран «Домой»»).
- `/download/` — страница загрузки приложения для Android, сам файл: `/last-flight.apk`.
- `/ws` — сервер для игры вдвоём через интернет. Хозяин открывает остров, игра показывает код из 5 знаков, второй игрок вводит этот код.
- `/health` — проверка, что сервер жив: сколько сейчас комнат и игроков.

## Как устроено

`server.js` на Node.js раздаёт файлы из папки `public` и пересылает сообщения между игроками одной комнаты. Сервер ничего не хранит: остров ведёт телефон хозяина, сохранения лежат на телефонах. Поэтому перезапуск сервера не теряет ничей прогресс, а только прерывает текущую игру вдвоём.

Если этот сервер недоступен, игра сама переходит на запасные публичные серверы.

## Запуск на Railway

1. На railway.com: New Project → Deploy from GitHub repo → выбрать этот репозиторий.
2. Railway сам увидит `package.json` и запустит `npm start`.
3. В настройках сервиса: Settings → Networking → Generate Domain. Получится адрес вида `last-flight-production.up.railway.app`.

## Проверить локально

```
npm install
npm start
```

Затем откройте http://localhost:8080.
